01 / Revision plan

Six ideas to know

Read each prompt, then answer the test question without looking back.

  1. 01

    Objects vs classes

    Know this: A class defines a type; an object is an instance of it.Test yourself: How does an object differ from its class?

  2. 02

    Encapsulation

    Know this: Keep data private and control access through methods.Test yourself: Why should a field often be private?

  3. 03

    Inheritance

    Know this: A subclass can reuse and extend a superclass.Test yourself: Which class receives inherited members?

  4. 04

    Polymorphism

    Know this: One reference can use different subclass implementations.Test yourself: Which overridden method runs at runtime?

  5. 05

    Aggregation vs composition

    Know this: Both are whole-part links, but ownership differs.Test yourself: Which one controls a part's lifetime?

  6. 06

    Singleton

    Know this: A class that guarantees exactly one instance, reached through a static getInstance().Test yourself: Why can you not use new? How do you get the instance?
