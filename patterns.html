Singleton

Exactly one instance, reached through a static getInstance().

final class Singleton {
  private static final Singleton INSTANCE
      = new Singleton();
  private Singleton() {}
  static Singleton getInstance() {
    return INSTANCE;
  }
}

Constructor chaining

No constructor declared? Java inserts a default one that calls super().

class Grandparent { }
class Parent extends Grandparent { }
final class Child extends Parent {
  Child() { super(); }
}

The chain runs Child → Parent → Grandparent → Object.
