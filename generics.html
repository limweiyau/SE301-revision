Generics

Six rules, each with a small example.

1 · Type parameters

<T> is a placeholder for the real type.

class Box<T> {
  private T value;
  T get() { return value; }
  void set(T v) { this.value = v; }
}

2 · Bounded type parameters

<T extends Number> accepts that type or a subclass.

static <T extends Number> double sum(T a, T b) {
  return a.doubleValue() + b.doubleValue();
}

3 · Unbounded wildcard ?

? means an unknown type; safe to read.

void sizeOf(List<?> list) {
  int n = list.size(); // type unknown, usable
}

4 · Upper bound ? extends T

Read only as T or a subtype (Number and below).

void printAll(List<? extends Number> nums) {
  for (Number n : nums) System.out.println(n);
}

5 · Lower bound ? super T

Write T or its supertypes (Integer and above).

void addOne(List<? super Integer> box) {
  box.add(1);
}

6 · Type erasure and no primitives

The type argument exists at compile time only. Use boxed types.

// Box<String> and Box<Integer> are both just Box at runtime
Box<Integer> n = new Box<>(); // Box<int> is invalid
