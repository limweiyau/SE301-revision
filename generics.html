Generics

Generics let one class or method work with many types, checked at compile time.

1. Type parameters

A <T> type parameter is a placeholder for the real type.

class Box<T> {
  private T value;
  T get() { return value; }
  void set(T v) { this.value = v; }
}

2. Bounded type parameters

<T extends Number> accepts only that type or its subclasses.

static <T extends Number> double sum(T a, T b) {
  return a.doubleValue() + b.doubleValue();
}

3. Wildcards

? means an unknown type.

void sizeOf(List<?> list) {
  int n = list.size(); // read-only, type unknown
}

? extends T — upper bound: read is safe (Number or a subtype).

void printAll(List<? extends Number> nums) {
  for (Number n : nums) System.out.println(n);
}

? super T — lower bound: writing is safe (Integer or a supertype).

void addOne(List<? super Integer> box) {
  box.add(1);
}

4. Generic methods

The type parameter belongs to the method, not the class.

static <T> T first(List<T> list) {
  return list.get(0);
}

5. Type erasure

The type argument exists at compile time only — the runtime sees the raw type.

// Box<String> and Box<Integer> are both just Box at runtime

6. No primitives

Use boxed types: Box<Integer> works, Box<int> does not.

Box<Integer> n = new Box<>();
