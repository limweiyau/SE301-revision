OOP principles

Seven ideas. Each with one small Java example.

1 · Encapsulation

Keep fields private; control access through methods.

final class Account {
  private double balance;
  void deposit(double amount) { balance += amount; }
  double balance() { return balance; }
}

2 · Inheritance

A subclass reuses and extends the superclass.

class Animal { String sound() { return "..."; } }
class Dog extends Animal {
  @Override String sound() { return "Woof"; }
}

3 · Polymorphism

One reference type, many runtime behaviours.

Animal pet = new Dog();
System.out.println(pet.sound()); // Woof, resolved at runtime

4 · Abstraction

Declare what; let subclasses decide how.

abstract class Shape {
  abstract double area();
}
final class Square extends Shape {
  private final double side;
  Square(double s) { side = s; }
  @Override double area() { return side * side; }
}

5 · Aggregation vs composition

Both are has-a links. Aggregation: parts passed in, may outlive the whole. Composition: the whole creates and owns the parts.

class Library {          // aggregation
  final List<Book> books;
  Library(List<Book> books) { this.books = books; }
}
class House {             // composition
  final List<Room> rooms =
      List.of(new Room("Kitchen"));
}

6 · Singleton

Exactly one instance, reached through a static getInstance().

final class Singleton {
  private static final Singleton INSTANCE = new Singleton();
  private Singleton() {}
  static Singleton getInstance() { return INSTANCE; }
}

7 · Constructor chaining

No constructor declared? Java inserts one that calls super(). It chains to Object.

class Child extends Parent {
  Child() { super(); } // inserted if you omit it
}

Child → Parent → ... → Object
