OOP principles, visually

Four concepts and the UML notation to draw them.

Aggregation

A “has‑a” link where parts exist independently and may be shared — drawn with a hollow diamond on the whole side.

final class Library {
  private final List<Book> books;
  Library(List<Book> books) { this.books = books; }
}

Composition

A “has‑a” link where the whole owns the parts’ lifetimes — drawn with a filled diamond on the whole side.

final class House {
  private final List<Room> rooms;
  House() {
    rooms = List.of(new Room("Kitchen"),
                    new Room("Bedroom"));
  }
}

Singleton

Exactly one instance, reached through a static getInstance().

final class Singleton {
  private static final Singleton INSTANCE = new Singleton();
  private Singleton() {}
  static Singleton getInstance() { return INSTANCE; }
}

Constructor chaining

No constructor declared? Java inserts a default one that calls super().

class Grandparent { }          // implicit: Grandparent() { super(); }
class Parent extends Grandparent { }   // implicit: Parent() { super(); }
final class Child extends Parent {
  Child() { super(); }              // explicit — javac inserts this if omitted
}

UML at a glance

Association

General link; no ownership implied.

Aggregation

Independent parts; hollow diamond.

Composition

Lifetime‑owned parts; filled diamond.

Inheritance

“Is‑a” link; triangle points to superclass.

1Exactly one.
1..*One or more.
0..*Zero or more.
